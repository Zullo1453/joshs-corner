# Security and privacy

Josh's Corner is designed for local use only. Its launcher binds Flask to `127.0.0.1`; do not expose the development server directly to the internet or forward its port from a router.

User data is stored locally in SQLite and the local uploads folder. Runtime databases, uploaded images, backups, caches, logs, environment files, and local configuration are excluded from Git.

If you find a security issue, do not post private records, backup files, or screenshots publicly. Open a minimal private report with reproduction steps that use fictional data, or contact the repository owner through the contact method listed on the repository profile once published.
